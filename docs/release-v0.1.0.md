## v0.1.0 · 第一次能用的版本

**下载** `ConcertoMaestro-standalone.zip`（17 MB）→ 解压 → 双击 `index.html`（Chrome / Edge）→ 选一首 → 空格。

不用装任何东西，不用联网。Safari 打不开本地音频引擎，会没有声音。

### 里面有什么

- **29 部协奏曲 / 86 个乐章**：Chopin 1–2、Beethoven 1/2/4/5、Mozart K37/39/40/41/175/413/450/456/466/467/482/491、Mendelssohn 1、Grieg、Tchaikovsky 1、Rachmaninoff 1–2、Prokofiev 2–3、Liszt 1、Brahms 2、Ravel G、Schumann
- 每个乐章都是**完整总谱里除钢琴以外的所有声部**
- 速度按小节分段、**实时可改**（不是重新渲染，改一个数字而已）
- A–B 循环、任意小节起跳、单声部静音
- **声部摆位 / 混响 / 演奏微时序** 三个开关
- 中英文界面，跟随浏览器语言

### 已知问题

- 反复记号不展开，带反复的乐章会比谱面短
- 打击乐只保留定音鼓
- 弦乐是单线（ABC 格式限制）
- Tchaikovsky 1 第一乐章的转录本身有重复段落，时长偏长

## v0.1.0 · first usable build

**Download** `ConcertoMaestro-standalone.zip` (17 MB) → unzip → double-click `index.html` (Chrome / Edge) → pick a piece → space.

Nothing to install, no network needed. Safari cannot start the audio engine from a local file — no sound there.

### What's in it

- **29 concertos / 86 movements**: Chopin 1–2, Beethoven 1/2/4/5, Mozart K37/39/40/41/175/413/450/456/466/467/482/491, Mendelssohn 1, Grieg, Tchaikovsky 1, Rachmaninoff 1–2, Prokofiev 2–3, Liszt 1, Brahms 2, Ravel G, Schumann
- every movement is the full score **minus the piano staves**
- tempo per bar section, **changed live** — no re-render, no pitch bend
- A–B loop, jump to any bar, mute individual parts
- **seating / reverb / micro-timing** switches
- Chinese + English UI, follows the browser language

### Known issues

- repeats are not expanded, so movements with repeats come out short
- only timpani survives from the percussion
- strings are single-line (an ABC format ceiling)
- Tchaikovsky 1/I has repeated passages written out in the source transcription, so it runs long
